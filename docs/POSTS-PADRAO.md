# POSTS PADRÃO

## Regras de capa para todos os posts do blog

### Estilo visual
- Fundo: preto puro com estrelas brancas aleatórias (estilo noite estrelada)
- Fonte: Playfair Display
- Cor do texto: branco puro
- Alinhamento: centralizado horizontal e vertical
- Sem barreiras, molduras ou elementos extras além do texto e estrelas

### Formatos
- **9:16** — `public/posts/{slug}.png`
  - Uso: cards da home, pastas, pins, listings
  - Resolução: 2160 x 3840 (4K portrait)
- **16:9** — `public/posts/{slug}-cover.png`
  - Uso: header dentro do post/article
  - Resolução: 3840 x 2160 (4K landscape)

### Regras de texto
- Título sempre centralizado
- Letras grandes, legíveis, com espaçamento adequado
- Se o título for longo, quebrar em até 2 linhas
- Nunca cortar texto nas bordas
- Sem texto descendo para baixo demais

### Observação
- Pins são personalizados e NÃO seguem este padrão
- Cada post deve ter EXATAMENTE 2 arquivos: `{slug}.png` e `{slug}-cover.png`
